# Qwen2.5-0.5B Structured-Answer LoRA

Fine-tuned Qwen2.5-0.5B-Instruct with LoRA to answer in a fixed format
(Summary / Key points / Next step), trained on a free Colab T4.

- Model: https://huggingface.co/Meow07/qwen2.5-0.5b-format-lora
- Live demo: https://huggingface.co/spaces/Meow07/format-lora-demo

## Result
Format compliance on 40 unseen questions: **39/40** fine-tuned vs **0/40** base.

## How it was built
1. Questions taken from HuggingFaceH4/no_robots.
2. Answers generated by Qwen2.5-1.5B-Instruct under a strict format prompt (self-distillation).
3. Filtered and normalized to 488 clean examples (440 train / 48 validation).
4. LoRA (r=16, alpha=32) on all attention and MLP projections, 2 epochs, lr 2e-4.
5. Evaluated on held-out questions, then pushed to the Hugging Face Hub.

## Files
- `format_lora_finetune.ipynb`: full pipeline (data generation, training, evaluation, upload)
- `train.json`, `val.json`: the dataset

## Limitations
- Teaches output format, not factual accuracy.
- The dataset answers were generated by a 1.5B model and contain factual errors.
  The data teaches output format only and should not be used as a knowledge source.
- Small synthetic dataset, single run, and the metric checks structure only.
